# קוד השרת (Google Apps Script) — תוכנית שנתית תשפ"ז, ישיבת אלוני הבשן

האתר (`src/App.jsx`) פונה לפריסת Web App של הסקריפט הזה דרך המשתנה `API_URL`.

## הקבצים

| קובץ | מה זה |
|---|---|
| `API.js` | קוד השרת המלא, כפי שהוא בעורך Apps Script (הורד עם clasp ב-2026-09-08) |
| `appsscript.json` | מניפסט הפרויקט: אזור זמן, V8, והגדרות ה-Web App (רץ כבעל הפרויקט, פתוח לכולם) |
| `.clasp.json` | מזהה הפרויקט, כדי ש-`clasp pull` / `clasp push` יעבדו מהתיקייה הזו |
| `legacy/api.gs` | גרסה ישנה מ-2026-07-02 שנמצאה במחשב. לא בשימוש, נשמרת להיסטוריה |

הסקריפט מוצמד לגיליון "תכנון שנתי תשפ"ז" (לשוניות: אירועים, צוות, תור התראות, הגדרות).
יומן הפעולות נכתב לקובץ נפרד, "יומן פעולות - מערכת ריכוז חברתי".

## שינוי אחד לעומת העורך

בפונקציית הבדיקה `sendSampleDigestEmail` הייתה כתובת מייל פרטית של איש צוות.
במאגר הציבורי היא הוחלפה ב-placeholder. מלבד זה הקובץ זהה למקור.

## עבודה עם clasp

```bash
npm install -g @google/clasp
clasp login
cd apps-script
clasp pull    # להוריד את הגרסה העדכנית מהעורך
clasp push    # להעלות שינויים לעורך (לא פורס! פריסה נעשית מהעורך או עם clasp deploy)
```
